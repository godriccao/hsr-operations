# 成就盘点

从手机菜单进入「成就」，先读分类概要及可见总数，再选择要盘点的分类。若当前界面提供关键词搜索，可用它查指定成就。结果保留分类或搜索词，覆盖范围按本次实际查看的页面记录。盘点期间只读，单项领取和批量领取按钮都留给用户。

## 选择盘点范围

- 需要完整账号账、补隐藏成就或核对目录差异时，扫完各类可见条目，再与同版本的全量目录做差集。
- 只要未完成名单，且同版本目录已证没有完成后才显示的缺口时，可做快速盘点。先实见未完成集中在列表顶部，确认到已完成有连续分界。用「（可见总数减已完成数）÷可见总数」粗找滑块位置，在首个已完成项附近核分界，回补边缘并逐名核到未完成分母。滑块位置只辅助导航，页数、首尾行和条目状态用新图确认。隐藏项、顺序变化或其他目录差异会影响目标时，改用全量。4.7 的「不屈者的荣光」目录 12 项均常显，可先用此法核分界。
- 用户已给出盘点范围时直接执行。需要估时，先用少量实机新图测每页完整行数、翻页耗时和部分行比例，再按可见总数估采集和补证用时。

## 逐名盘点

1. 用当前原生窗口截图定位列表、滑块及其轨道。页面、窗口位置或遮挡变化后重新取图。通过获准的鼠标左键，点击滑块下方实际可见的轨道。发键或点击前照常核控制归属与游戏前台，使用桥时逐条等新增 ACK。新图同时看见首行和滑块位置变化，才记一次翻页。
2. 每页记完整标题、解锁状态、领取状态、游戏显示的奖励及进度或计数。把已解锁但待领与已领分开记。字段看不清或界面没显示时记「未知」。
3. 可用 Windows Graphics Capture（WGC）只读采目标窗口的原尺寸画面。先与新鲜窗口图核同一分类、首行、滑块及当前状态。OCR 用卡片边框定位每行，留截图和行位置。高亮背景可能让相邻卡片被读成一段，可换到实际分隔的边框列检查。边缘行已看清完整标题和状态仍可入账，缺字段时保留对照片。标题、状态、重名或数值有疑问时回原图人工核实。
4. 全量先按一个方向扫各类，再反向补边缘与未重叠处。尽量让相邻页有至少一行完整重叠，按分类、完整标题和可确认的目录 ID 去重。跨帧补单行需确认对得上同一标题和条件。核实每类的唯一已完数及未完数分别达到本次界面分母，再登记全量完成。计数相等只支持账号可见覆盖，外部目录集合要按条目对齐。

2026-11-20 的 Windows 实机全量盘点约 42 分钟，包含改 OCR 与补漏。稳定段相邻采集约 0.81 秒一页，完整熟练耗时待测。此前逐页窗口截图小样首张至末张约 56 秒，五次轨道翻页均可见变化，测试中的滚轮未推进列表。遇采集滞留旧界面时回到新鲜窗口截图。

## 成就解锁规划

1. 用当前账号的逐项实机画面或可追溯的该账号历史记录，将候选标为已完成、明确未完成或状态未知。以明确未完成与满足可达条件的差集候选为基础规划。目录候选保留证据状态，实际触发后更新账号账。
2. 按用户本轮范围筛选。逐项核版本、入口和可达性，确认角色或队伍、互斥选项及限时条件。根据预计星琼与从可操作到解锁验收的预计墙钟时间排优先级。同一锚点或关卡的目标可合批，先确认队伍、触发顺序和选项能同时满足各项条件。
3. 每项用短计划写清可核起点、触发条件、成功信号和止损条件。入口或触发证据不足的难关放入待补证。现场条件不符或达到止损条件时，记录已验证的断点，切换到下一项。
4. 执行后分别记录已解锁、待领和实际到账。星琼到账以实际领取结果为准。仅委托规划时交付行动清单。单项及批量领取均默认由用户操作。

### 全量目录与攻略来源

全量对表可用 BWIKI 成就索引核标题、分类、版本及奖励，用 Nanoka 同版本中文目录的 ID 和显示类型区分常显、仅藏描述与完成后才显示。目录口径、同名条目、别名、互斥分支分别记录。对照账号逐项已完名单做差集，保留已证未完和只有目录证据的候选。隐藏条目一起做差集，无需逐条在游戏内搜索；确要走某条路线时再核本次可达条件。账号与目录只有其中一方见到的条目保留原来源与证据。

按题型选证据。游戏文本优先核原条件。战斗和特殊互动可查米游社、17173 可追溯的作者实景，地图定位可查 Sidus 的图，连续动作可对照 Wotpack 实录或 nyacchi 的分段实景。用本账号入口、楼层、地标、机关和反馈复核攻略适用性。核定触发条件、角色、剧情前置或限时后，以游戏弹条或账号状态验收。涉及不可逆互斥选项时先核已选分支。

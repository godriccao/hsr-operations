# 迷钟操作

目标流程：用当前棋盘与攻略终态规划一个行走阶段，将已确定的动作合并执行，再检查钟表小子的位置和齿轮变化。帮派迷钟现有实测是逐步完成记录；整段批处理效果待后续实机验证。

## 进入与定位

1. 与当前游戏操作者确认输入归属；一个操作者负责键鼠，其他线程负责攻略、求解和记录。
2. 在探索场景靠近迷钟，按当前交互提示进入。记录迷钟名称、地图、棋盘、当前齿轮和角色位置。
3. 核对攻略与棋盘的固定黑色路径、可动块形状、镜面及起终点。帮派迷钟的实测记录见 [帮派迷钟](gang-clock.md)。
4. 当前块状态不清楚时，用界面左下角重置恢复可辨识起点，并截图记录。已经进入后续阶段时，先确认重置影响范围。
5. 读取 [Windows 控制](windows-control.md)，核对当前窗口与坐标映射；窗口移动、缩放或分辨率变化后重新校准。

## 分段求解与执行

- 先在图上确定连续路径：起点、实体块、镜像块、齿轮。分别记录每块的当前朝向、目标朝向或滑轨目标位置。
- 攻略终态图用于确定目标状态；旋转次数由当前状态计算。只对棋盘和阶段一致的实测记录复用固定次数。
- 将本阶段编成有序动作列表：目标块、点击次数或拖拽起终点、按住时长、动作间隔、预期终态。一次调用执行该阶段已确定的动作。
- 普通连续动作按实测输入节奏执行；阶段结束留出自动行走时间，随后截图确认角色到达齿轮、新齿轮出现或完成状态。棋盘变化后再执行下一段。
- 镜面使用内部玻璃空白区作拖拽热点。镜子顶部装饰可能不响应；镜面效果以路径和边界位置判定。
- 若回执失败、焦点转移、画面与预期不同，结束当前批次并释放输入，读取当前状态后重新规划。回执不明的点击先查状态再决定重试，避免多转一圈。

## 结束与奖励

1. 最终金齿轮到达后，等待谜题返回探索画面。
2. 查看迷钟是否还有交互，完成唤醒及收尾对话；对话选项以当前画面为准。
3. 核实完成标志、奖励提示或生成的奖励对象，再领取可见奖励。分别记录“路径完成”“收尾完成”“奖励已核实”。奖励数值记录直接画面证据或用户明确确认，并注明来源。
4. 更新地图查漏清单：迷钟完成状态与地图宝箱计数分别记录。恢复为本任务临时改动的设置，按当前游戏任务安排继续探索或交还控制。

## 改进与复用

在过关、卡点影响决策或批次结束时集中记录前置状态、实际走通的动作、验收画面与耗时。固定动作只在前置状态一致时复用；从重置开始的全流程须另有完整验证。

分开测量输入间隔、批次间隔、截图耗时和完整谜题耗时。把稳定阶段合并为一次批处理，减少每动作一次模型往返。当前目标为常规动作间隔 1–2 秒，阶段行走/动画时间单独记录。空闲时基于实际失败或计时改进一项，并用下一次实际谜题验证。

关卡记录保存来源、适用棋盘、执行日期和验证范围；控制桥的会话口令、账号信息及临时进程标识留在本机运行环境。

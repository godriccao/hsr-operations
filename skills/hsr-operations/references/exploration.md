# 清图与导航

读仓库 `docs/OPERATIONS.md` 的寻宝、楼层、位移、多帧和批次流程，按 `docs/BATCHES.md` 的地标核实已有路段。当前位置、已领奖励与剩余分项在本地记录，不从历史实例接续账号状态。

每批先读地图名、版本、角色层、显示层和目标层。寻宝道具按名称选择，优先用当前账号的寻宝标记确认未领取的候选，再查攻略入口。标记切层后分别核角色所在层和目标层。隔层时在地图停一下，先确定可传锚、连通楼梯或实际入口。同一锚点的旧截图供辨认地标，领取状态以本次画面为准。靠近交互读 F 文案，重叠项用滚轮选择。探测器没有目标不能证明全部贼灵、谜题和隐藏奖励已完成。

同一区域关闭重开、缩到最小后仍裁掉目标锚时，可先传送到另一区域已确认可达的锚，落地后从区域列表重开目标地图。实测跨传渡画泉隐后恢复妖都默认视图，跨传海原公园后恢复观览云岛站北部。右侧区域列表的滚动位置与地图画布独立；目标行未露出时，按实际滚动条定位，再核锚名、楼层和「传送」按钮。云岛恢复北部后实传「『狐图图』观览云岛店」。

区域大地图仍裁掉目标锚时，可选当前可见且离目标更近的蓝锚，核对名称、楼层和「传送」按钮。实际落地后重开地图，让画布按新落点居中，再找下一锚。2026-11-21 用公开仓库 `ba052a3` 的 `bridge_sender.py` 实测坠星的摇篮，原生窗口截图核地图与奖励，OBS 核走位。经「通往群星的前哨站」→「无量塔沉眠之海」→「星星的起点」分段到达。若当前图没有合适的可见锚点，先核对区域和楼层。

从「星星的起点」离开机车正面，沿北侧低地穿过岩脊缺口，见蓝紫篮和蓝花地后找篮右前方的独立橙银箱。靠近核 `F`「普通战利品」，本次实收星琼 ×5、乐园纪念币 ×15、信用点 ×750。[普通箱实景](https://kakinblog.com/wp-content/uploads/2026/07/houkais16-2-1.jpg)

坠星的摇篮 #13 位于「星星的起点」西侧。若气气狸狸已标出普通「战利品」，用「星星的起点」和「无量塔沉眠之海」两个锚点对齐实机地图与攻略图，确认黄标落在 #13，再选「开始追踪」。从「星星的起点」背离半埋机车，经浅洞、双棕榈和暖灯下到开阔沙滩东侧的绿色窄道。先沿地图向西略偏南，顺通路绕过右侧圆石，出窄道到开阔岸后再转西南贴近黄标。用同缩放地图核对位移，镜头转动后先短移校准。到水岸时，以斜车厢和临水紫蓝篮定位，找斜车厢旁可单独交互的橙银箱。[跑图视频（约 1:19）](https://www.4399youpai.com/video/5259150.html#t=79) · [攻略 #13](https://kakinblog.com/houkais-senrihin-tuisei-yurikago/) · [攻略实景](https://kakinblog.com/wp-content/uploads/2026/07/houkais13-1-1.jpg)

靠近后核对 `F`「普通战利品」，开箱后看奖励弹条和地图发现数。2026-11-21 在 Windows 用当天的本地守卫输入编排（`guarded_bridge.mjs` 和 `guarded_bridge_host.js`）实测，OBS 核走位及交互，原生窗口截图核奖励。实收星琼 ×5、乐园纪念币 ×15、信用点 ×750，地图发现数增加 1。

在 Windows MCP 的 `Screenshot` 会触发输入租约的宿主上，地图核图使用当前获准的原生窗口截图或只读 OBS。精确点击仍按实际画面校准，并按 [Windows 控制](windows-control.md) 核实控制状态。

传送或转镜后短移校准方向；同缩放下按地图背景位移除以按住时间估速度。确认直路合批到下一地标，每条指令正常就绪并等回执。转角、变层、战斗和领奖时核画面。碰撞、焦点、错层分别调查，避免反复同向顶墙。

合批前备起点、镜头朝向、动作和要验收的落点。拥有并行分析时，在加载或战斗期间备同层顺路点和一个可切换的后备点，操控线程用短上下文和低推理确认地标后执行。到安全节点交接唯一输入权，带上当前状态、首批动作和奖励前值。

多帧用同一门框、墙角、栏杆交叉核位置，固定 HUD 和角色居中箭头不代表世界无位移。第一张可操作画面保持为计时起点。角色、窗口、缩放或视角变化重新校准；历史按键时长仅在相同起点与朝向复测。

相机狸先交谈触发黄圈，按青标找变身物并普攻显形，再交谈收尾；假角色型目标可能需要战斗。按实际奖励、地图分项和交互状态验收。地点命中率分母为已执行且有明确目标的批次，未验收批次单列。

临时设置先记原值，任务结束恢复。攻略图、截图和本地状态自行按生命周期保留，公开前移除账号、通知及个人路径。性能口径见仓库 `docs/PERFORMANCE.md`。

## 灰图与未露出的锚点

先核对区域和楼层，缩到最小，再拖地图画布露出边缘独立地形，以固定图元随画布移动确认拖动有效。若目标仍无可用锚，沿已核实的任务入口或步行路线进区。传送前核实蓝锚实名及「传送」按钮，派发后以落地画面验收。

永夜「沉沦暮城」奥赫玛 1F 实测向右上拖画布，露出左下《天空旧诗》的蓝色叹号。点「前往」落冷照浴宫，沿雅努斯密径去云石市集救民。从长梯上有箱阳台，回身走另一段长梯上躺椅台，经可行走的蓝布坡到阿克蒙所在的红瓦屋顶。沿屋脊向左，与女性残像交谈取吊坠。

任务指向「云端遗堡」后，按 V 打开遗堡 3F 地图，缩到最小并向上拖，露出最南小厅。实见蓝锚「泣夜残壁」和传送按钮后派发传送。南厅此前被裁出画布，锚点何时点亮未核。

## 云端遗堡东立体厅「遗堡之底」#39 普通箱

从 2F「遗堡之底」沿蓝徽墙右侧通道到圆盘，见 F「上升」后乘盘。穿过巨门，在右手取首枚符文，再经浅金十字桥与蓝石宽阶到中央室，以第二符文座定位。

从中央室西侧短阶进浅金横廊，越过中间十字岔直走到西端符文座。由符文座向图北，沿黑色机械的红横灯一侧走到浅灰小双门。门面有低浮雕，左门框有蓝光缝，右边是白柱。到门前灰砖处核 F「普通战利品」。立体图缩小后可对照中央室与西横廊。[横廊与小门原图（毛豆 #39）](https://i.17173cdn.com/2fhnvk/YWxqaGBf/cms3/TgcuYWbsCFBotBr.jpg)

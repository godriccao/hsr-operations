# 文件桥、接管与回执

## 正常执行条件

原生 CUA 取图后照常查 Windows MCP ControlStatus。ready 表示本次正常就绪，ai 时等待受支持的就绪路径，user 时立即让出。每条命令前再次核归属与游戏前台；一次 ready 不能授权后面整段无人检查。12.6 秒可作为一次等待上限，500ms 轮询仅为原项目发送端参数，超时停止。

AHK 桥本身不能查询宿主的 ControlStatus。调用它的 agent/sender 负责正常归属查询；独立辅助也须遵守同样规则。桥只防失焦和超时，用户可能在焦点未变时接管，因此不能把前台检查当作用户授权。

当前宿主若仅允许 CUA 输入，就使用该接口允许的能力；所需持续按键能力不可用时停止该动作。公开代码不增加宿主权限，不修改租约、凭据、权限检查或旧桥期限。

## 单槽协议

运行目录包含 `command.txt`、`claimed-command.txt` 和 `status.log`。只有一个 sender 和一个桥。先确认槽空，再在同目录写临时文件、关闭句柄，以不覆盖目标的原子改名提交 command.txt。UTF-8 无 BOM、无尾换行。认领后未完成的命令也属于占用状态。

| 命令 | 含义 |
|---|---|
| `ping` | 不发键，新增 PONG |
| `stop` | 退出并释放按键 |
| `keys|W+D|500` | 组合键按下、保持、抬起 |
| `click|120,160|80` | 游戏 client 像素坐标点击，第三字段沿用协议但不表示点击按住时长 |

允许字母数字、Space、Enter、Escape、Tab、方向、LShift、LCtrl、F1 至 F12。keys 时长裁到 40–1000ms；ACK 回显原始命令，所以 ACK 的 4000 不证明按住了 4 秒。直走 3 秒分三条 1000ms，每条等新 ACK。超过 30 秒的待发指令过期。新桥保留这些行为，配置了游戏路径、当前会话截止和运行目录；需重新现场验收。

## 对齐回执

桥没有序号、没有高精度执行时间戳。sender 在提交前记 status.log 的字节位置与本次命令，提交后只读新增部分；看到本命令的完整 `ACK <原命令>` 才继续，同名连续命令也须逐条消费。读取后及时关闭句柄，不持续占用日志。派发和观察到 ACK 的时点在 sender 用同一时钟记；回执耗时包含轮询和读取等待，不等于纯按键耗时。

每批输出 `dispatch <epoch_ms> <command>` 和 `ack <epoch_ms> <command>` 可由 codex_timing.py 对齐。它只配顺序单槽日志；重复、交错、不完整或跨命令调用的日志须先调查，不能将匹配数等同游戏成功。

`tools/bridge_sender.py` 提供 Windows 单槽 sender 库，默认没有现场 CLI。调用方必须传入实际 `control_status()` 和 `foreground_ok()` 回调，以及本次通道已获授权的状态。回调每次查询真实宿主，不缓存 ready；没有可靠回调时不运行。该库用独占 sender.lock、提交前日志偏移、逐条新增回执和超时停止保证调度顺序，返回相对派发与 ACK 时间。首次桥启动先等 READY，再由同一库发送 ping。读取 `status.log` 遇 Windows 共享或字节锁错误 32、33 时，在本次等待截止时间内从原偏移继续读，期间照常检查控制归属与前台。访问拒绝等其他读取错误立即返回。遇超时就停止该批，最新画面用于核实原命令有无执行。

FOCUS_REQUIRED 表示该命令没有执行。ACK 缺失可能是日志写冲突，动作可能已经生效。任一失败均停止余下动作，不覆盖槽、不重放整批；核当前画面、按键和认领状态。遗留命令只有在确认已过期、内容和时间稳定后才由唯一操作者无覆盖归档。桥错误弹窗不点 Continue 重放。恢复后先新 PONG 和新画面，再计划。

写 `status.log` 遇 Windows 错误 32 或 33 时，桥分别等待 15、30、60 毫秒后重试写入同一条状态。持续冲突时桥以退出码 32 结束，其余系统错误保留原退出码。状态写入重试期间不会重放输入。ACK 仍缺失时停止派发，恢复后从新画面核实实际位置。

## 时敏辅助

连续至少两条含 `Space` 的跳跃命令时，调用方可传 `dispatch_interval_ms=(370, 420)`。这个例子把相邻两条的派发间隔设为 370 至 420 毫秒，首跳立即走常规校验。上一条收到新 ACK 后，sender 等到间隔下限再重新查控制归属与前台。到上限仍未准备好时停止该批。实战间隔按关卡与起跳条件校准。

`rewind-cue.ahk --live X Y [1至3] <配置文件>` 在独立胶囊青色边沿松开 Space，再次按下。总预算 12 秒，失焦、客户区改变或会话过期即停并释放。必须先进入针盘、校准当前客户区坐标、确认初始非青，且桥无待发命令。运行它时暂停桥 sender，用户接管立刻紧急停止。结果写配置的 RuntimeDir。

`camera-step.ahk <配置文件> X Y` 相对转镜，delta 限 ±2400，角度需现场校准。`click-aware-game.ahk <配置文件> X Y [DX DY]` 用 0≤X,Y<1 的客户区比例点击；拖拽增量也按比例，分 20 步各 20ms。两者同样需事前 ready 检查，按当前权限正常调用。点击起点或拖动中的实测光标未到要求位置时，返回退出码 8；若已按下鼠标会立即释放。点击或拖动完成后释放鼠标并退出。重试前先核输入归属、前台和客户区坐标。
